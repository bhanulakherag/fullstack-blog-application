# Full Stack Blog Application

A complete full-stack web application built for the internship task using Node.js, Express, MongoDB, and Vanilla JavaScript.

## 🚀 Features
- **User Authentication:** Secure user registration and login functionality.
- **CRUD & Dynamic Blogs:** Create and read dynamic blog posts directly from the database.
- **Responsive UI:** Clean, mobile-friendly interface for reading and publishing blogs.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose ODM)
